# Karthikeyan's Portfolio

A Next.js portfolio for software engineering, AI and automation, and embedded systems projects.

## Run locally

```bash
npm install
npm run dev
```

## Folder structure

```text
src/
  app/          Routes and root layout
  components/   Layout, home, about, projects, and shared UI
  content/      Site and page data
  lib/          Navigation and project helpers
  styles/       Global styles
public/         Images and animations
```
